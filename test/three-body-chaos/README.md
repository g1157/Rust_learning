# 三体问题混沌演示

## 项目简介

本项目使用Rust实现了三体问题的数值模拟，演示经典力学中的混沌现象。通过对比稳定配置（拉格朗日三角形）和混沌配置（随机初始条件），展示初始条件敏感性和能量守恒验证。

## 功能特性

- [x] **三体系统模拟器**：使用Velocity Verlet算法进行高精度数值积分
- [x] **稳定配置**：拉格朗日三角形，三个等质量天体在等边三角形顶点做周期运动
- [x] **混沌配置**：相近质量随机分布，展示混沌轨道特征
- [x] **初始条件敏感性测试**：微小扰动（10^-6）导致轨道差异放大
- [x] **轨道可视化**：使用plotters库生成XY平面轨道投影图
- [x] **能量守恒检验**：计算动能和势能，验证数值算法精度

## 核心算法

### 数值积分方法

使用**Velocity Verlet算法**进行时间演化：
```
a(t) = F(r(t))/m
r(t+dt) = r(t) + v(t)*dt + 0.5*a(t)*dt²
v(t+dt) = v(t) + 0.5*[a(t) + a(t+dt)]*dt
```

### 万有引力

归一化单位系统，引力常数 G = 1.0：
```
F_ij = G * m_i * m_j / r_ij²
```

| 参数 | 值 | 说明 |

| 模拟时长 | 50.0 | 时间单位 |
| 记录间隔 | 10步 | 减少数据量 |

## 混沌条件

混沌现象的特征：
1. **对初始条件敏感**：微小扰动（10^-6）经过时间演化可能放大数个数量级
2. **能量剧烈变化**：在混沌配置中，天体可能发生逃逸，导致系统能量显著变化
3. **轨道不规则**：与稳定配置的规则周期运动形成鲜明对比

稳定配置（拉格朗日三角形）：
- 三个等质量天体
- 初始位于等边三角形顶点
- 初始速度满足圆周运动条件
- 能量守恒误差极小（< 0.001%）

## 输出文件

运行程序后会生成以下文件：

### 图像文件（PNG）
- `stable_orbit.png` - 稳定配置轨道图（拉格朗日三角形）
- `chaotic_orbit.png` - 混沌配置轨道图
- `sensitivity_test.png` - 初始条件敏感性对比图（左：原始系统，右：扰动系统）

### 数据文件（CSV）
- `stable_data.csv` - 稳定配置的轨迹数据
- `chaotic_data.csv` - 混沌配置的轨迹数据

CSV格式：
```
time,body1_x,body1_y,body1_z,body2_x,body2_y,body2_z,body3_x,body3_y,body3_z
```
