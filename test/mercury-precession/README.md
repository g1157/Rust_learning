# Mercury Perihelion Precession

水星近日点进动模拟 - 验证广义相对论对行星轨道的修正效应。

## 项目简介

模拟水星在太阳引力场中的轨道运动，通过添加广义相对论修正项来观察近日点进动现象。这是验证广义相对论的经典实验之一。

## 物理背景

水星的近日点每世纪进动约 43 角秒，这一现象无法用牛顿力学解释，是爱因斯坦广义相对论的重要验证。

## 引力模型

**带广义相对论修正的引力加速度**:
```
a = -GM/r² × [1 + α × 3GM/(rc²)] × r̂
```

其中：
- `α = 0`: 牛顿引力（无进动）
- `α = 1`: 标准广义相对论
- `α > 1`: 增强的相对论效应

## 水星轨道参数

| 参数 | 值 |
|------|-----|
| 半长轴 | 0.387098 AU |
| 离心率 | 0.2056 |
| 轨道周期 | 0.2408 年 |

## 数值方法

- **Velocity Verlet 算法**: 二阶辛积分器
- **时间步长**: 0.00001 年
- **模拟周期**: 100 个轨道

## 测试系数

程序测试不同的广义相对论修正系数 α = {0.0, 0.5, 1.0, 2.0, 3.0}

## 输出

- `mercury_precession_comparison.png` - 不同修正系数下的轨道对比图
- 控制台输出每世纪进动角秒数
