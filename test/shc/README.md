# Schrodinger Equation Solver

薛定谔方程求解器 - 使用打靶法求解一维谐振子本征能量。

## 项目简介

使用打靶法（Shooting Method）结合 Runge-Kutta 4 阶积分器，求解一维量子谐振子的薛定谔方程，找到基态能量。

## 物理问题

**定态薛定谔方程**:
```
-ℏ²/(2m) × d²ψ/dx² + V(x)ψ = Eψ
```

**势函数**: V(x) = ½x²（谐振子势）

## 数值方法

### 打靶法（Shooting Method）

1. 猜测能量 E
2. 从边界条件 ψ(-L) = 0 积分到 ψ(L)
3. 检查 ψ(L) 是否满足边界条件
4. 使用二分法调整 E

### Runge-Kutta 4 阶积分

将二阶微分方程转化为一阶方程组：
- ψ' = φ
- φ' = 2m/ℏ² × (V(x) - E) × ψ

## 参数设置

| 参数 | 值 |
|------|-----|
| 积分范围 | [-5, 5] |
| 步长 dx | 0.01 |
| 能量搜索范围 | [0.4, 0.6] |
| 收敛精度 | 10⁻⁵ |

## 预期结果

谐振子基态能量理论值: E₀ = ½ℏω = 0.5（在 ℏ = m = ω = 1 的单位制下）
