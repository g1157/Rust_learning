# Jupiter-Earth 双行星太阳系统模拟

## 项目简介

这是一个实现 **Example 4.2** 的 Rust 项目,模拟包含地球和木星的双行星太阳系统。使用 **Euler-Cromer 数值方法**计算行星轨道运动。

## 物理模型

### 初始条件
- **地球**:
  - 初始位置: (1.0, 0.0) AU
  - 初始速度: (0.0, 2π) AU/年 (圆轨道)
  - 质量: 3×10⁻⁶ M☉

- **木星**:
  - 初始位置: (5.2, 0.0) AU
  - 初始速度: (0.0, 2π/√5.2) AU/年 (圆轨道)
  - 质量: 9.5×10⁻⁴ M☉

### Euler-Cromer 方法

在每个时间步 i 进行以下计算:

1. **计算距离**:
   - 地球到太阳: r_e(i) = √[x_e(i)² + y_e(i)²]
   - 木星到太阳: r_j(i) = √[x_j(i)² + y_j(i)²]
   - 地球到木星: r_EJ(i) = √[(x_e(i)-x_j(i))² + (y_e(i)-y_j(i))²]

2. **更新速度** (先更新速度是 Euler-Cromer 的关键):
   ```
   v_e,x(i+1) = v_e,x(i) - 4π²·x_e(i)/r_e(i)³·Δt - 4π²·(M_j/M☉)·[x_e(i)-x_j(i)]/r_EJ(i)³·Δt
   v_e,y(i+1) = v_e,y(i) - 4π²·y_e(i)/r_e(i)³·Δt - 4π²·(M_j/M☉)·[y_e(i)-y_j(i)]/r_EJ(i)³·Δt
   ```
   
   木星的速度更新类似。

3. **更新位置** (使用新的速度):
   ```
   x_e(i+1) = x_e(i) + v_e,x(i+1)·Δt
   y_e(i+1) = y_e(i) + v_e,y(i+1)·Δt
   ```

## 编译和运行

### 编译项目
```bash
cargo build --release
```

### 运行模拟
```bash
cargo run --release
```

## 输出文件

运行后会生成两个文件:

1. **jupiter_earth_orbit.csv**: 包含所有时间步的轨道数据
   - 格式: earth_x, earth_y, jupiter_x, jupiter_y

2. **jupiter_earth_orbit.png**: 轨道可视化图
   - 蓝色线: 地球轨道
   - 红色线: 木星轨道
   - 黄色点: 太阳

## 模拟参数

- 时间步长: Δt = 0.001 年 (约 8.77 小时)
- 模拟总时间: 20 年
- 总步数: 20,000

## 物理单位

- 距离: 天文单位 (AU)
- 时间: 年 (year)
- 质量: 太阳质量 (M☉)
- 速度: AU/年

## 依赖项

- `plotters`: 用于生成轨道可视化图

## 代码结构

- `Planet`: 行星结构体,包含位置、速度和质量
- `SolarSystem`: 太阳系统模拟器,实现 Euler-Cromer 方法
- `step()`: 执行单个时间步的更新
- `simulate()`: 运行完整的模拟过程
- `save_to_csv()`: 保存轨道数据到 CSV
- `plot_orbits()`: 绘制轨道可视化图

## 观察结果

从输出可以看到:
- 地球保持在约 1.0 AU 的轨道上运行
- 木星保持在约 5.2 AU 的轨道上运行
- 行星间的引力相互作用导致轨道略有变化
- Euler-Cromer 方法能够很好地保持轨道稳定性
