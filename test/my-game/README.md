# My Game

基于 Macroquad 的 2D 射击游戏 - 躲避敌人并射击得分。

## 项目简介

一个完整的 2D 射击游戏，使用 Macroquad 游戏框架开发，包含星空背景着色器、粒子爆炸效果和高分系统。

## 游戏特性

- 动态星空背景（GLSL 着色器）
- 粒子爆炸效果
- 高分记录保存
- 多种游戏状态（主菜单、游戏中、暂停、游戏结束）

## 游戏操作

| 按键 | 功能 |
|------|------|
| 方向键 | 移动玩家 |
| 空格 | 发射子弹 / 开始游戏 |
| ESC | 暂停 / 退出 |

## 游戏机制

- 玩家控制黄色圆形
- 绿色方块从上方掉落
- 射击方块获得分数（分数 = 方块大小）
- 碰到方块游戏结束

## 技术亮点

- **着色器**: 自定义 GLSL 星空效果
- **粒子系统**: 使用 `macroquad_particles` 实现爆炸
- **状态机**: 游戏状态管理
- **持久化**: 高分保存到文件

## 运行

```bash
cd test/my-game
cargo run --release
```

## 依赖

- `macroquad` - 游戏框架
- `macroquad_particles` - 粒子效果
