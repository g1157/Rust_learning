## 1. 引言与 UX 目标

### 1.1 文档目的

本文档定义 **TDGL Simulator Dashboard** 的用户体验目标、信息架构、用户流程和视觉设计规格。该仪表盘将为 GPU 加速的 TDGL 超导涡旋模拟器提供统一的交互界面，取代当前分散的 CLI 命令和 Python 脚本。

### 1.2 目标用户画像

| 画像 | 描述 | 核心需求 |
|------|------|----------|
| **研究者** | 物理学研究生/博士后，熟悉 TDGL 理论，需要快速迭代实验参数 | 参数调节直观、结果可视化即时、数据导出便捷 |
| **数据分析师** | 需要批量运行仿真并分析结果，可能不熟悉底层物理 | 批处理配置简单、进度可见、结果对比方便 |
| **学习者** | 课程学生，首次接触超导涡旋仿真 | 界面友好、参数有解释、有预设配置可用 |

### 1.3 可用性目标

1. **易学性**: 新用户 5 分钟内能启动第一次仿真
2. **效率**: 常用操作（调参、运行、查看结果）≤3 次点击
3. **错误预防**: 参数输入有范围验证和即时反馈
4. **可记忆性**: 界面布局一致，用户离开后能快速回忆操作方式

### 1.4 设计原则

1. **科研优先** - 界面服务于科研工作流，不追求花哨效果
2. **数据可见** - 关键物理量始终可见，无需切换页面
3. **即时反馈** - 参数变化立即反映在预览/估算中
4. **渐进复杂** - 默认简单模式，高级选项可展开
5. **可复现** - 每次运行的配置自动保存，支持一键复现

## 3. 用户流程

### 3.1 核心流程总览

| # | 流程 | 用户目标 | 频率 |
|---|------|----------|------|
| 1 | 快速交互仿真 | 调参并实时观察涡旋行为 | 高 |
| 2 | κ Sweep 扫参 | 获取 depinning 曲线，提取 κ_c | 高 |
| 3 | 批量相图生成 | 扫描多参数空间，生成相图 | 中 |
| 4 | 结果分析与对比 | 查看历史运行，对比不同配置 | 高 |
| 5 | 配置复现 | 从历史记录重新运行实验 | 中 |

### 3.2 流程 1: 快速交互仿真

**用户目标**: 快速调整参数，实时观察涡旋动力学行为

```
启动应用 → 加载默认配置 → 调整参数 → 点击开始 → 实时观察
    ↓                                              ↓
  可选: 加载预设                              暂停/调参/继续
                                                   ↓
                                            停止 → 自动保存
```

**关键交互**:
- 滑块调节 flux_n 时即时显示对应 B 值
- κ 可在运行中实时调整
- 暂停后可修改参数再继续

### 3.3 流程 2: κ Sweep 扫参

**用户目标**: 自动扫描 κ 范围，获取 depinning 曲线

```
选择 κ Sweep 模式 → 配置 sweep 参数 → 开始 → 实时显示曲线
                                              ↓
                                    完成 → 显示 κ_c → 保存结果
```

**界面状态**:
```
┌─ Sweep 进度 ─────────────────────────┐
│ κ = 0.02 (3/6)  ████████░░░░ 50%     │
│ 阶段: Measure   ███████░░░ 70%       │
│ ETA: 3m 25s                          │
├──────────────────────────────────────┤
│ 实时 Depinning 曲线:                  │
│   |v|      ___○___                   │
│    │    __○                          │
│    │  _○                             │
│    ○─────────────→ κ                 │
│              ↑ κ_c ≈ 0.025           │
└──────────────────────────────────────┘
```

### 3.4 流程 4: 结果分析与对比

**对比视图**:
```
┌─ 运行对比 ─────────────────────────────────────────┐
│           运行 A                 运行 B            │
├────────────────────────┬──────────────────────────┤
│ flux_n: 209            │ flux_n: 209              │
│ defect_mode: random    │ defect_mode: lattice  ⚡ │
│ κ_c: 0.025             │ κ_c: 0.032            ⚡ │
├────────────────────────┴──────────────────────────┤
│ Depinning 曲线对比图                               │
```

```
┌─────────────────────────────────────┐

│ ≈ B = 0.0200                       │  ← 关联计算值

```

## 6. 动画与微交互

### 6.1 动画设计原则

| 原则 | 说明 |
|------|------|
| 功能优先 | 动画服务于信息传达，非装饰 |
| 快速响应 | 大多数动画 < 200ms |
| 物理感 | 使用 ease-out 缓动 |
| 可中断 | 动画可被新操作打断 |
| 性能敏感 | 不影响仿真帧率 |

### 6.2 核心动画

| 动画类型 | 时长 | 缓动 |
|----------|------|------|
| 按钮悬停 | 80ms | ease-out |
| 状态转换 | 200ms | ease-out |
| 面板折叠 | 150ms | ease-out |
| 数值高亮 | 200ms | ease-out |
| 进度更新 | 100ms | linear |
| 涡旋出现 | 200ms | elastic |
| 脉冲循环 | 1500ms | sine |

### 6.3 关键动画效果

**运行按钮脉冲** (Running 状态):
```
亮度: 100% → 120% → 100% (循环 1.5s)
边框发光效果
```

**数值变化高亮**:
```
数值变化时: 白色 → 青色高亮 → 白色 (200ms)
```

**涡旋标记出现**:
```
透明度: 0% → 100%
大小: 0.5x → 1.0x (弹性缓动)
```
