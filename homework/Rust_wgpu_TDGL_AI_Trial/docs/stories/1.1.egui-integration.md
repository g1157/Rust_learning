# Story 1.1: egui 基础集成

## Status

**Ready for Review**

---

## Story

**As a** 研究者/开发者,
**I want** 在现有的 TDGL 仿真窗口中集成 egui UI 框架,
**so that** 我可以通过图形界面控制仿真参数，而不是依赖命令行参数。

---

## Story Context

**Existing System Integration:**
- 集成位置: `src/main.rs` - 现有的 wgpu + winit 渲染循环
- 技术栈: Rust + wgpu 23 + winit 0.30
- 遵循模式: 现有的 `ApplicationHandler` trait 实现
- 接触点: `App` 结构体、`render()` 方法、事件循环

**Reference Document:** `docs/front-end-spec.md`

## Acceptance Criteria

### 功能需求

1. egui 面板能够在现有热力图窗口上正确渲染
2. egui 面板显示在窗口左侧，宽度约 280px
3. 面板中显示基本信息：当前步数 (step_count)、仿真时间、flux_n 值
4. 热力图渲染不受 egui 集成影响，仍然正常显示

### 集成需求

5. 现有的键盘交互 (A 键切换显示模式) 继续正常工作
6. 现有的 `--headless` 模式不受影响（headless 模式下不加载 egui）
7. 窗口关闭行为保持不变

### 质量需求

8. 集成后仿真帧率保持 ≥ 60 FPS（交互模式）
9. 代码通过 `cargo build` 和 `cargo clippy` 无错误/警告
10. 新增依赖版本与现有 wgpu 23 兼容

**现有渲染流程** (`render()` 方法):
```rust
fn render(&mut self) {
    let frame = self.surface.get_current_texture()?;
    let view = frame.texture.create_view(...);
    let mut enc = self.device.create_command_encoder(...);

    // Render pass - 绘制热力图
    {
        let mut rp = enc.begin_render_pass(...);
        rp.set_pipeline(&self.render_pipeline);
        rp.set_bind_group(0, &self.render_bgs[...], &[]);
        rp.draw(0..3, 0..1);
    }

    self.queue.submit(Some(enc.finish()));
    frame.present();
}
```

**事件处理** (`window_event()` 方法):
- `KeyCode::KeyA` - 切换显示模式
- `CloseRequested` - 退出应用

### egui-wgpu 集成模式

**推荐集成方式**:
```rust
// 1. 初始化
let egui_ctx = egui::Context::default();
let egui_state = egui_winit::State::new(
    egui_ctx.clone(),
    egui_ctx.viewport_id(),
    &window,
    None,
    None,
    None,
);
let egui_renderer = egui_wgpu::Renderer::new(
    &device,
    surface_format,
    None,
    1,
    false,
);

// 2. 事件处理
fn window_event(&mut self, event: &WindowEvent) {
    let response = self.egui_state.on_window_event(&self.window, event);
    if response.consumed {
        return;  // egui 消费了事件
    }
    // 现有事件处理...
}

// 3. 渲染
fn render(&mut self) {
    let raw_input = self.egui_state.take_egui_input(&self.window);
    let full_output = self.egui_ctx.run(raw_input, |ctx| {
        egui::SidePanel::left("params")
            .default_width(280.0)
            .show(ctx, |ui| {
                ui.heading("仿真参数");
                ui.label(format!("Step: {}", self.step_count));
            });
    });

    // 处理 egui 输出
    self.egui_state.handle_platform_output(&self.window, full_output.platform_output);

    // 渲染热力图 (现有代码)...

    // 渲染 egui
    let paint_jobs = self.egui_ctx.tessellate(full_output.shapes, full_output.pixels_per_point);
    let screen_descriptor = egui_wgpu::ScreenDescriptor {
        size_in_pixels: [self.config.width, self.config.height],
        pixels_per_point: full_output.pixels_per_point,
    };

    // 在同一个 render pass 或新的 pass 中渲染 egui
    self.egui_renderer.render(&mut rp, &paint_jobs, &screen_descriptor);
}
```
