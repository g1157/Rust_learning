### Depinning 曲线 κ_c 检测

```rust
// 简单阈值法：找到 |v| 首次超过阈值的 κ 值
fn detect_kappa_c(data: &[(f32, f32)], threshold: f32) -> Option<f32> {
    data.iter()
        .find(|(_, v)| *v > threshold)
        .map(|(k, _)| *k)
}
```

### 预设存储路径

```rust
use directories::ProjectDirs;

fn presets_dir() -> PathBuf {
    ProjectDirs::from("", "", "TDGL-Simulator")
        .map(|d| d.config_dir().to_path_buf())
        .unwrap_or_else(|| PathBuf::from("."))
        .join("presets")
}
```
