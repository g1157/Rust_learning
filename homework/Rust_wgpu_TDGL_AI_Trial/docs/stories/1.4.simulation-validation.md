## Dev Notes

### 物理公式参考

#### 涡旋晶格间距 (Abrikosov 三角晶格)
```
a₀ = (2Φ₀ / √3 B)^(1/2) = 1.075 × √(Φ₀/B)

其中:
- Φ₀ = h/2e = 2.07 × 10⁻¹⁵ Wb (磁通量子)
- B = φ/dx² (磁场强度)
- φ = 2πn / (Nx × Ny) (plaquette flux)
```

#### 磁场与涡旋数关系
```
n_v = B × A / Φ₀ = flux_n

对于 128×128 网格, dx=1:
- flux_n = 16 → 预期 16 个涡旋
- flux_n = 64 → 预期 64 个涡旋
- flux_n = 209 → 预期 209 个涡旋
```

#### Depinning 临界行为
```
v ∝ (κ - κ_c)^β  当 κ > κ_c

理论预期:
- β = 0.5 (mean-field)
- β = 0.5-0.65 (实验观测范围)
- ν = 1.0-1.3 (相关长度指数)
```

#### Matching Field
```
第一匹配场: B₁ = n_defects × Φ₀ / A
分数匹配: B = B₁/2, B₁/3, 2B₁/3 处也有较小峰值

匹配条件: |n_vortices - n_defects| ≤ tolerance
```

### 最近邻距离计算算法

```rust
fn calculate_mean_nearest_neighbor(positions: &[(f32, f32)]) -> f32 {
    if positions.len() < 2 {
        return 0.0;
    }

    let mut total_dist = 0.0;
    for (i, &(x1, y1)) in positions.iter().enumerate() {
        let mut min_dist = f32::MAX;
        for (j, &(x2, y2)) in positions.iter().enumerate() {
            if i != j {
                let dist = ((x2 - x1).powi(2) + (y2 - y1).powi(2)).sqrt();
                min_dist = min_dist.min(dist);
            }
        }
        if min_dist < f32::MAX {
            total_dist += min_dist;
        }
    }
    total_dist / positions.len() as f32
}
```

### 幂律拟合 (最小二乘法)

```rust
// 对 log(v) vs log(κ - κ_c) 进行线性拟合
// 斜率即为 β 指数
fn fit_power_law(data: &[(f32, f32)], kappa_c: f32) -> (f32, f32) {
    let filtered: Vec<_> = data.iter()
        .filter(|(k, v)| *k > kappa_c && *v > 0.0)
        .map(|(k, v)| ((k - kappa_c).ln(), v.ln()))
        .collect();

    // 线性回归: y = β*x + c
    // 返回 (β, R²)
    linear_regression(&filtered)
}
```
