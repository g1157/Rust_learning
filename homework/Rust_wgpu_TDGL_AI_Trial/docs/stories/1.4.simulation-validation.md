## Dev Notes

### 物理公式参考

#### 涡旋晶格间距 (Abrikosov 三角晶格)
```
a₀ = (2Φ₀ / √3 B)^(1/2) = 1.075 × √(Φ₀/B)

其中:
- Φ₀ = h/2e = 2.07 × 10⁻¹⁵ Wb (磁通量子)
- B = φ/dx² (磁场强度)
- φ = 2πn / (Nx × Ny) (plaquette flux)
```

#### 磁场与涡旋数关系
```
n_v = B × A / Φ₀ = flux_n

对于 128×128 网格, dx=1:
- flux_n = 16 → 预期 16 个涡旋
- flux_n = 64 → 预期 64 个涡旋
- flux_n = 209 → 预期 209 个涡旋
```

#### Depinning 临界行为
```
v ∝ (κ - κ_c)^β  当 κ > κ_c

理论预期:
- β = 0.5 (mean-field)
- β = 0.5-0.65 (实验观测范围)
- ν = 1.0-1.3 (相关长度指数)
```

#### Matching Field
```
第一匹配场: B₁ = n_defects × Φ₀ / A
分数匹配: B = B₁/2, B₁/3, 2B₁/3 处也有较小峰值

匹配条件: |n_vortices - n_defects| ≤ tolerance
```

### 最近邻距离计算算法

```rust
fn calculate_mean_nearest_neighbor(positions: &[(f32, f32)]) -> f32 {
    if positions.len() < 2 {
        return 0.0;
    }

    let mut total_dist = 0.0;
    for (i, &(x1, y1)) in positions.iter().enumerate() {
        let mut min_dist = f32::MAX;
        for (j, &(x2, y2)) in positions.iter().enumerate() {
            if i != j {
                let dist = ((x2 - x1).powi(2) + (y2 - y1).powi(2)).sqrt();
                min_dist = min_dist.min(dist);
            }
        }
        if min_dist < f32::MAX {
            total_dist += min_dist;
        }
    }
    total_dist / positions.len() as f32
}
```

### 幂律拟合 (最小二乘法)

```rust
// 对 log(v) vs log(κ - κ_c) 进行线性拟合
// 斜率即为 β 指数
fn fit_power_law(data: &[(f32, f32)], kappa_c: f32) -> (f32, f32) {
    let filtered: Vec<_> = data.iter()
        .filter(|(k, v)| *k > kappa_c && *v > 0.0)
        .map(|(k, v)| ((k - kappa_c).ln(), v.ln()))
        .collect();

    // 线性回归: y = β*x + c
    // 返回 (β, R²)
    linear_regression(&filtered)
}
```

### Debug Log References

1. **性能问题 (2025-12-25)**: 程序启动后未响应
   - 原因: `validation_panel.rs` 中 `calculate_measured_spacing` 和 `detect_symmetry` 使用 O(n²) 算法，涡旋数多时卡顿
   - 修复: 简化算法，移除不必要的空间哈希优化（对典型涡旋数 <200 不需要）

2. **晶格间距偏差过大 (2025-12-25)**: 偏差 34-65%
   - 原因 1: 验证数据混淆了涡旋和反涡旋位置
   - 修复: 只使用正涡旋位置计算间距
   - 原因 2: 理论间距基于 flux_n，但实际涡旋数不同
   - 修复: 分离 `flux_n`（目标）和 `n_vortices`（实际），偏差基于实际涡旋数计算
   - 原因 3: 涡旋分布不均匀，部分涡旋聚集拉低平均值
   - 修复: 使用中位数代替平均值，对异常值更鲁棒

3. **Matching Field 显示错误 (2025-12-25)**
   - 原因: `--defect-mode lattice` 忽略 `--defect-count`，缺陷数由 spacing 决定
   - 说明: 这是设计行为，文档已更新说明
