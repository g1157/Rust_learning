## Story

**As a** 研究者,
**I want** 通过图形界面调整仿真参数（flux_n、κ、缺陷配置等）,
**so that** 我可以快速迭代实验而无需修改命令行参数。

---

## Acceptance Criteria

1. egui 成功集成到现有 wgpu 渲染循环
2. 左侧面板显示可折叠的参数组（仿真参数、缺陷配置、运行模式）
3. 参数变更实时绑定到 `RunConfig`
4. 运行控制按钮（开始/暂停/停止/重置）功能正常
5. 深色主题应用，符合 front-end-spec 配色方案
6. 现有热力图渲染不受影响

- **egui-wgpu**: 0.30 (wgpu 23 兼容)

### 关键集成点

**现有代码位置 (`src/main.rs`):**

| 行号范围 | 内容 | 集成方式 |
|----------|------|----------|
| 29-31 | egui imports (已存在) | 使用现有 |
| 64-68 | `DefectMode` 枚举 | UI 绑定 |
| 88-105 | `RunConfig` 结构体 | UI 参数源 |
| 107-124 | `RunMode` 枚举 | UI 模式选择 |

**渲染循环集成:**

```rust
// 在 window_event 中添加:
let response = self.egui_state.on_window_event(&window, &event);
if response.consumed { return; }

// 在 render 中添加:
let raw_input = self.egui_state.take_egui_input(&window);
let full_output = self.egui_ctx.run(raw_input, |ctx| {
    // UI 绘制代码
});
```
