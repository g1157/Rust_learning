## 0. 项目一句话

用 **Rust + wgpu(WebGPU)** 在 GPU 上并行求解二维 **时间依赖 Ginzburg–Landau（TDGL）** 的简化模型，加入 **钉扎势/缺陷**，研究缺陷分布对涡旋结构与去钉扎（depinning）阈值的影响，并给出 **CPU vs GPU** 性能标度。

## 2. 从零学习路线（只学项目需要的）

### 2.1 数值基础（最低门槛）
你需要理解：
- 2D 拉普拉斯算子（5 点 stencil）
- 显式 Euler 时间推进
- 为什么步长 dt 太大会炸（稳定性直觉）

最低目标：能写出
\[
\psi^{n+1} = \psi^n + \Delta t \cdot F(\psi^n)
\]

### 2.2 物理直觉（够做项目即可）
你要能用一段话解释：
- 序参 \(\psi\) 是什么（复数场）
- 涡旋是什么（相位绕数 ±2π 的拓扑缺陷）
- 钉扎为什么重要（抑制涡旋运动→降低耗散→提高临界电流）

### 2.3 TDGL（先做简化版）
从 **无矢势 A 的简化 TDGL** 起步（可控、易出图）：

\[
\partial_t \psi = \nabla^2 \psi + \alpha(\mathbf r)\,\psi - |\psi|^2\psi
\]

- \(\psi\)：复数序参（GPU 用 `vec2<f32>` 表示）
- \(\alpha(\mathbf r)\)：材料/缺陷场。钉扎可通过局部降低 \(\alpha\) 来实现。

## 4. 实现路线（MVP → 研究版）

> 原则：先 CPU/简化版保证正确，再搬 GPU；每次只增加一个维度，避免「数值错 + shader 错」叠加。

### 阶段 0：wgpu compute 骨架（最小闭环）
- 两个 storage buffer（ping-pong）
- compute shader：`out = in + 常数` 验证数据流
- 可选：回读少量数据到 CPU 做 sanity check

### 阶段 1：TDGL 更新核（核心）
- WGSL 里实现：
  - 5 点 stencil 拉普拉斯（周期边界）
  - 非线性项 \(|\psi|^2\psi\)
  - 显式 Euler 更新
- 从小网格（256×256）+ 小 dt 起步

### 阶段 2：缺陷/钉扎势（alpha 场）
- 再加一个同尺寸 `alpha` buffer（f32）
- 更新时读取 `alpha[idx]`
- 支持鼠标绘制缺陷（局部修改 alpha）

### 阶段 3：可视化（GPU 上直接显示）
- 将 |psi| 映射成纹理显示（避免每帧读回）

### 阶段 4：研究实验与扫参
- 扫：缺陷强度 × 密度 × 分布
- 输出：去钉扎阈值/平均漂移速度/涡旋统计量
- 性能：256^2/512^2/1024^2 steps/s

## 6. AI 提示词包（按顺序喂给 Claude/Codex）

### Prompt 1：wgpu compute 最小可运行
> 用 Rust + wgpu + winit 写一个最小程序：创建 device/queue，创建两个 storage buffer（ping-pong），每帧 dispatch 一个 compute shader，把输入 buffer 的 vec2<f32> 数组更新到输出 buffer。提供 Cargo.toml，可编译运行。

### Prompt 2：2D 网格索引与周期边界
> 在 WGSL 中实现二维网格索引 (x,y)->idx，以及周期边界取邻居 (x±1,y±1)。写一个 compute：out[x,y]=in[x,y]+in[x+1,y] 的测试验证 stencil 访问正确。

### Prompt 3：复数运算与 TDGL 更新核
> 用 vec2<f32> 表示复数，实现复数乘法、模长平方、与标量乘。实现 TDGL：psi_next = psi + dt*(laplacian(psi)+alpha*psi - |psi|^2*psi)。alpha 为一张同尺寸的 f32 场（buffer）。给出 WGSL + Rust bind group layout。

### Prompt 4：alpha 场与鼠标绘制缺陷
> 在 Rust 端维护 alpha 的 GPU buffer；鼠标点击/拖拽时在半径 r 内把 alpha 减小（钉扎）。尽量只更新局部区域（queue.write_buffer 子段写入）。

### Prompt 5：可视化 |psi|
> 把 |psi| 映射为颜色在窗口显示（灰度/热力图均可）。优先不把整张场读回 CPU：建议在 fragment shader 采样 psi buffer 计算 |psi| 并上色。

### Prompt 6（进阶）：涡旋检测（相位绕数）
> 实现相位绕数检测：对每个小网格单元取四个角点相位，计算相位差并 unwrap，总和≈±2π 则标记 vortex。输出 vortex 数量随时间到 CSV。

## 一、把“看到涡旋”变成“测到涡旋”

### 1) 涡旋检测与追踪（强烈推荐，投入小、研究味最大）

你现在只看 (|\psi|)，下一步做：

* **相位绕数（phase winding）**：对每个小网格单元，累加四边相位差（unwrap 到 (-\pi,\pi)），总和接近 (\pm 2\pi) 就是一个涡旋/反涡旋。
* 输出随时间的曲线：

  * (N_v(t)) 涡旋数
  * 缺陷区域内的涡旋占比
  * 最近邻距离分布/径向分布（可选）

这一步会让你的报告从“图像很炫”变成“我做了可量化统计”。

### 2) 结构因子/相关函数（可选）

* 计算 (S(\mathbf k)) 或 (g(r)) 来描述涡旋是否形成有序晶格、缺陷是否打散秩序。

## 二、提出一个清晰的“研究问题”并做参数相图

你现在有 (\alpha(\mathbf r)) 缺陷场，最自然的深度方向是：

### 3) 去钉扎（depinning）阈值曲线（论文感很强）

加一个“驱动”并定义一个阈值：

* 驱动可以非常简化：施加一个等效外力/相位梯度项（或在更新里加入一个小偏置项，让涡旋有整体漂移趋势）。
* 定义观测量：平均漂移速度 (\langle v \rangle) 或单位时间内涡旋位移。
* 扫参数做图：

  * 缺陷强度 (V_p) × 缺陷密度 (n_p) × 半径 (r_p)
  * 得到阈值 (F_c(V_p, n_p, r_p)) 或 “速度-力曲线”

这会让你的项目从“模拟器”变成“做实验”。

### 4) 随机 vs 周期缺陷对比

同样的缺陷密度下：

* 随机缺陷：更像真实材料
* 周期阵列：更像人工纳米图案化 pinning
  对比阈值、涡旋分布、结构因子差异——非常容易写成一节结论。

## 三、让模型更“物理真实”（更硬核，但也更有深度）

你现在用的是简化 TDGL（无矢势）。如果你想在物理上更上一层：

### 5) 加入磁场/矢势（Gauge-covariant TDGL）

把拉普拉斯换成规范协变形式（离散上就是带 link 变量/相位因子）：

* 这样涡旋产生有了更严格的“外场来源”，也更接近 Type-II 超导下的磁通涡旋图景。
* 还能做：外场大小 vs 涡旋密度、涡旋晶格等更经典的物理结果。

这一步会显著增加推导与实现复杂度，但深度也最大。

### 6) 加热噪声（热涨落）

加入随机噪声项（满足合适的统计性质），研究温度升高时：

* 涡旋更容易解钉扎
* 结构有序性下降
  这能把你的项目自然扩展成“温度相图”。

## 四、数值方法层面的深度（让你“像数值分析论文”）

### 7) 用更稳定/高效的时间推进

显式 Euler 很直观，但你可以做一个方法对比：

* 半隐式（线性项隐式、非线性显式）
* RK2/RK4
* 自适应 dt（根据最大梯度/局部变化控制）

然后给出：误差、稳定性窗口、性能对比。

### 8) 收敛性与一致性验证（一定要有，能显著提升可信度）

至少做两类：

* **网格收敛**：256^2 vs 512^2 vs 1024^2，同一物理设置下统计量是否收敛
* **时间步收敛**：dt 减半统计量变化是否减少

你已经有 CPU/GPU 单步一致性，这非常好；再补上“物理量随 dt/dx 收敛”，可信度会跳一档。
