**方法二**：针对一系列试探的 T_c 值，绘制 log(M) 与 log(T_c - T) 的关系图。当 T → T_c 时能得到直线的那个 T_c 就是优选值，该直线的斜率即为 β。

## 二、物理原理

本节为第一次接触伊辛模型的读者提供完整的物理背景。

### 2.1 什么是伊辛模型？

伊辛模型（Ising Model）是统计物理中最简单、最重要的**相变模型**之一，由 Ernst Ising 于 1925 年提出。它用于描述铁磁材料中磁性的产生与消失。

**核心思想**：
- 材料由大量"自旋"组成，每个自旋只能指向"上"(+1) 或"下"(-1)
- 相邻自旋之间存在相互作用，倾向于同向排列
- 温度升高会破坏这种有序性

### 2.2 哈密顿量（系统能量）

系统的总能量由以下公式描述：

$$
H = -J \sum_{\langle i,j \rangle} s_i s_j - \mu h \sum_i s_i
$$

| 符号 | 物理含义 | 说明 |
|:----:|:--------:|:----:|
| J | 交换耦合常数 | J > 0 表示铁磁耦合（自旋倾向同向） |
| s_i | 第 i 个自旋的取值 | 只能是 +1 或 -1 |
| ⟨i,j⟩ | 最近邻求和 | 只对相邻的自旋对求和 |
| h | 外加磁场强度 | 作业一中 h=0，作业二中 h≠0 |
| μ | 磁矩 | 设为 1 |

**物理意义**：
- **第一项**：相邻自旋同向时 s_i·s_j = +1，能量降低（-J < 0）
- **第二项**：自旋沿外场方向排列时能量降低

### 2.3 磁化强度

磁化强度 M 是系统有序程度的度量：

$$
M = \frac{1}{N} \sum_i s_i
$$

| M 的值 | 物理状态 |
|:------:|:--------:|
| M = +1 | 所有自旋向上（完全有序） |
| M = -1 | 所有自旋向下（完全有序） |
| M ≈ 0 | 自旋随机取向（完全无序） |

### 2.4 相变与临界温度

这是伊辛模型最迷人的特性——**相变**：

| 温度区间 | 系统状态 | 物理相 |
|:--------:|:--------:|:------:|
| T < T_c | 自发磁化，M ≠ 0 | **铁磁相** |
| T > T_c | 无自发磁化，M → 0 | **顺磁相** |
| T = T_c | 临界点，系统涨落发散 | **临界态** |

**临界温度的精确值**（设 J = k_B = 1）：

| 晶格类型 | 临界温度 T_c | 配位数 |
|:--------:|:------------:|:------:|
| 正方形 | 2/ln(1+√2) ≈ **2.269** | 4 |
| 三角形 | 4/ln(3) ≈ **3.641** | 6 |

### 2.5 临界指数 β 与幂律（公式 8.17）

在临界温度附近，磁化强度遵循**幂律**：

$$
M \sim (T_c - T)^\beta \quad \text{当 } T \to T_c^-
$$

这就是题目中提到的**公式（8.17）**。

**关键结论**：
- 二维伊辛模型的精确解给出 **β = 1/8 = 0.125**
- 这个值与晶格形状（正方形、三角形）**无关**——这就是**普适性**

### 2.6 普适性（Universality）

**普适性**是相变理论的核心概念：

> 临界指数只依赖于系统的**维度**和**对称性**，与微观细节无关。

这意味着：
- 正方形晶格和三角形晶格虽然结构不同
- 但它们都是二维系统，具有相同的 Z₂ 对称性
- 因此它们的临界指数 β 相同

### 2.7 高温极限与式（8.8）

在极高温度下（T >> T_c），热运动占主导，自旋间的相互作用可以忽略。此时每个自旋独立地响应外场，平均值为：

$$
\langle s_i \rangle = \tanh\left(\frac{\mu H}{k_B T}\right)
$$

这就是题目中提到的**式（8.8）**。设 μ = k_B = 1，简化为：

$$
M_{\text{theory}} = \tanh\left(\frac{H}{T}\right)
$$

**温度对偏差的影响**：
- T = 100：自旋几乎独立，式（8.8）非常准确
- T = 30, 10：相互作用开始显著，偏差增大
- T → T_c：临界涨落主导，式（8.8）完全失效

### 2.8 为什么需要蒙特卡洛？

对于 N 个自旋的系统，共有 2^N 种可能的构型：
- 32×32 晶格：2^1024 种构型（远超宇宙原子数！）
- 精确求和不可能

**解决方案**：Metropolis 蒙特卡洛方法——只抽样"重要"的构型。

### 2.9 Metropolis 算法

这是一种**重要性抽样**方法，按玻尔兹曼分布 exp(-H/T) 生成构型：

```
算法步骤：
1. 随机选择一个自旋 s_i
2. 计算翻转该自旋导致的能量变化 ΔE
3. 接受准则：
   - 若 ΔE ≤ 0（能量降低）：接受翻转
   - 若 ΔE > 0（能量升高）：以概率 exp(-ΔE/T) 接受翻转
4. 重复 N 次 = 完成 1 次"扫描"(sweep)
5. 平衡化后，测量物理量的平均值
```

**能量变化公式**：

$$
\Delta E = 2 s_i \left( J \sum_{j \in \text{nn}(i)} s_j + \mu h \right)
$$

**优化**：只需查看 4 个（正方形）或 6 个（三角形）近邻，是 O(1) 操作！

## 三、估算 β 的两种方法

题目明确要求使用以下两种方法：

### 方法一：M^(1/β*) vs T 线性度分析

由幂律 M = A(T_c - T)^β，取 1/β 次幂：

$$
M^{1/\beta} = A^{1/\beta}(T_c - T)
$$

这表明 M^(1/β) 与 T 应该呈**线性关系**。

**算法**：
1. 扫描 β* = 0.05, 0.06, ..., 0.20
2. 对每个 β*，计算 M^(1/β*) vs T 的线性拟合 R²
3. R² 最大的 β* 即为最佳估计

**优势**：不需要预先知道 T_c！

### 方法二：log(M) vs log(T_c - T) 拟合

对幂律取对数：

$$
\log M = \beta \log(T_c - T) + \log A
$$

在 log-log 图上，**斜率即为 β**。

**注意**：需要 T_c 的估计值。对于正方形晶格，使用 T_c ≈ 2.269。

### 5.3 Metropolis 算法核心

```rust
fn metropolis_sweep(&mut self, temperature: f64, field: f64, rng: &mut StdRng) {
    let n = self.spins.len();
    let beta = 1.0 / temperature;
    
    for _ in 0..n {
        // 1. 随机选择一个自旋
        let idx = rng.gen_range(0..n);
        
        // 2. 计算能量变化
        let sum_neighbors: i32 = self.neighbors[idx]
            .iter()
            .map(|&j| self.spins[j] as i32)
            .sum();
        let delta_e = 2.0 * (self.spins[idx] as f64) 
                    * (sum_neighbors as f64 + field);
        
        // 3. Metropolis 接受准则
        if delta_e <= 0.0 || rng.gen::<f64>() < (-beta * delta_e).exp() {
            self.spins[idx] = -self.spins[idx];  // 翻转！
        }
    }
}
```
