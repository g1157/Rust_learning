**二、实验原理**

**2.1 伊辛模型**

伊辛模型（Ising Model）是统计物理中描述铁磁相变的经典模型。系统由位于晶格格点上的自旋组成，每个自旋只能取 $+1$（向上）或 $-1$（向下）。

系统能量由哈密顿量描述：

$$H = -J \sum_{\langle i,j \rangle} s_i s_j - \mu h \sum_i s_i, \quad s_i = \pm 1$$

```
符号      含义                      说明
─────────────────────────────────────────────────────
J         交换耦合常数              J > 0 表示铁磁耦合
s_i       第 i 个自旋               取值 +1 或 -1
⟨i,j⟩     最近邻求和                只对相邻自旋对求和
h         外加磁场强度              作业一中 h=0
μ         磁矩                      设为 1
```

**2.2 磁化强度与相变**

磁化强度定义为所有自旋的平均值：

$$M = \frac{1}{N} \sum_i s_i$$

系统存在临界温度 $T_c$，在此温度发生 **相变**：

```
温度区间        物理行为                      相态
─────────────────────────────────────────────────────
T < Tc          自发磁化，M ≠ 0               铁磁相
T > Tc          热涨落主导，M → 0             顺磁相
T = Tc          临界点，关联长度发散          临界态
```

二维晶格的精确临界温度（设 $J = k_B = 1$）：

```
晶格类型      临界温度 Tc                  配位数
─────────────────────────────────────────────────────
正方形        2/ln(1+√2) ≈ 2.269          z = 4
三角形        4/ln(3) ≈ 3.641             z = 6
```

**2.3 临界指数与普适性「公式 8.17」**

在临界温度附近，磁化强度遵循幂律：

$$M \sim (T_c - T)^\beta \quad \text{当 } T \to T_c^-$$

> **★ 二维伊辛模型精确解**：$\beta = \frac{1}{8} = 0.125$

***普适性***（Universality）是相变理论的核心概念：临界指数只依赖于系统的 **维度** 和 **对称性**，与晶格细节（正方形、三角形）无关。

**2.4 高温单自旋近似「公式 8.8」**

在 $T \gg T_c$ 时，自旋间相互作用可忽略，磁化强度满足：

$$M_{\text{theory}} = \tanh\left(\frac{H}{T}\right)$$

温度降低时，与此近似的偏差增大，体现了 *自旋相互作用* 的影响。

**2.5 Metropolis 算法**

对于 $N$ 个自旋的系统，共有 $2^N$ 种构型，无法精确求和。Metropolis 算法通过 **重要性抽样** 解决此问题：

```
算法步骤：
1. 随机选择一个自旋 s_i
2. 计算翻转该自旋导致的能量变化 ΔE
3. 接受准则：
   - 若 ΔE ≤ 0（能量降低）：接受翻转
   - 若 ΔE > 0：以概率 exp(-ΔE/T) 接受翻转
4. 重复 N 次 = 完成 1 次 "sweep"
5. 平衡化后测量物理量
```

能量变化公式：

$$\Delta E = 2 s_i \left( \sum_{j \in \text{nn}(i)} s_j + h \right)$$

**三、实验内容与结果**

**3.1 作业一：临界指数 β 估算**

**实验设置**

```
参数              值
────────────────────────────────
晶格尺寸          32 × 32
平衡化步数        1000 sweeps
测量步数          3000 sweeps
温度范围          0.6 Tc 到 Tc
外场              h = 0
```

**方法一：$M^{1/\beta^*}$ vs $T$ 线性度分析**

由幂律 $M = A(T_c - T)^\beta$ 可得 $M^{1/\beta} = A^{1/\beta}(T_c - T)$，即 $M^{1/\beta}$ 与 $T$ 呈线性关系。

扫描不同的 $\beta^*$ 值，选择 $R^2$ 最大的作为最佳估计。

> **优势**：不需要预先知道 $T_c$

**方法二：$\log(M)$ vs $\log(T_c - T)$ 拟合**

取对数：

$$\ln M = \beta \ln(T_c - T) + \ln A$$

斜率即为 $\beta$。根据题目提示，只使用 $2.0 < T < T_c$ 范围内的数据。


**物理解释**：

式（8.8）$M = \tanh(H/T)$ 是 **单自旋近似** 的结果，假设自旋之间独立。

- **$T = 100$**（约 $44$ 倍 $T_c$）：热能 $k_B T \gg J$，自旋几乎独立，近似极好
- **$T = 10$**（约 $4$ 倍 $T_c$）：相互作用开始显著，偏差明显
- **$T \to T_c$**：临界涨落发散，单自旋近似完全失效

**四、结论**

1. **临界指数**：使用两种方法估算得到 $\beta \approx 0.12$，与 Onsager 精确解 $\beta = 1/8 = 0.125$ 符合良好（误差 $< 6\%$）。在题目指出的 $2.0 < T < T_c \approx 2.27$ 范围内，幂律「公式 8.17」确实成立。

2. **普适性验证**：正方形和三角形晶格给出 **相同的临界指数**，尽管它们的临界温度（$2.27$ vs $3.64$）和配位数（$4$ vs $6$）不同。这验证了普适性——临界指数只依赖于维度（2D）和对称性（$Z_2$）。

3. **高温近似验证**：$T = 100$ 时，$M(H)$ 与 $\tanh(H/T)$ 符合极好（偏差 $< 0.1\%$）；温度降低时偏差增大（$T = 10$ 时约 $40$ 倍），验证了自旋相互作用的影响。

4. **编程实践**：使用 Rust 语言实现了模块化代码，近邻预计算提升效率，支持正方形和三角形晶格，自动生成可视化图表。
