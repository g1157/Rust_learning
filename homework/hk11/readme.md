## 核心算法 (伪代码)
```
draw_branch(起点, 长度, 角度, 深度):
    如果 深度 == 0: 返回
    
    终点 = 起点 + (长度 * cos(角度), 长度 * sin(角度))
    画线(起点, 终点)
    
    # 左分支：角度 - 30°，长度缩短 0.7 倍
    draw_branch(终点, 长度*0.7, 角度-30°, 深度-1)
    
    # 右分支：角度 + 30°，长度缩短 0.7 倍
    draw_branch(终点, 长度*0.7, 角度+30°, 深度-1)
```
