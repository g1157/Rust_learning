# 波动方程数值求解 - 习题 6.2 和 6.3

## 教材内容主要讲了哪些东西

这一段教材的主题是波动方程的推导、数值求解以及算法稳定性。它主要围绕以下四个方面展开，但下面全部使用连续文本描述，不用列表或渲染。

教材首先从弦的一小段出发，通过受力分析得到波动方程。采用小角度近似后，可以得到：

μ * (d^2 y / dt^2) = T * (d^2 y / dx^2)

整理成标准形式：

d^2 y / dt^2 = c^2 * (d^2 y / dx^2)，其中 c = sqrt(T / μ)

教材指出，波动方程的一般解由两个方向的波组成：

y(x,t) = f(x - c t) + g(x + c t)

分别对应向右传播和向左传播的波。

接着，教材将波动方程做离散化。空间二阶导数用差分：

(d^2 y / dx^2) ≈ (y[i+1] - 2 y[i] + y[i-1]) / (Δx)^2

时间二阶导数用差分：

(d^2 y / dt^2) ≈ (y^(n+1) - 2 y^n + y^(n-1)) / (Δt)^2

最终得到关键的更新公式（教材公式 6.6）：

y[i]^(n+1) = 2*(1 - r^2)y[i]^n - y[i]^(n-1) + r^2(y[i+1]^n + y[i-1]^n)，其中 r = c * Δt / Δx

教材解释，只需保存三个时间层即可：上一层、当前层、下一层。边界条件可以是固定端（两端 y=0）或自由端。

在数值稳定性方面，教材强调 r 的作用非常重要。教材指出以下事实：

当 r = 1 时，算法最准确，因为误差抵消得最好。

当 r < 1 时，算法稳定，但会在波遇到边界反射时产生明显的小波纹（教材称为 extra bumps）。

当 r > 1 时，算法完全不稳定，数值会迅速发散，因为离散网格每一步只能传播 Δx 距离，而物理波速要求每一步传播 c * Δt，如果这个速度超过网格能表达的最大速度（即 Δx / Δt），算法就会爆炸。

教材还展示了多种波传播现象，例如高斯波包分裂成左右两波、固定端反射的翻转、以及在不同波速区域出现反射和透射。

这些现象为理解习题提供了必要的背景。

## 与习题 6.2 有关的内容

习题 6.2 要求你比较不同 r 值的数值行为。教材中与此直接相关的内容集中在对 r 的讨论上。

教材指出 r > 1 会导致算法发散；r < 1 虽然稳定但会在反射处产生小误差；r = 1 是最好的选择。教材还特别提醒你比较波在固定端反射时的形状，因为额外的数值误差通常在反射时最明显。

因此，习题 6.2 实质上是让你：

使用公式 y[i]^(n+1) = 2*(1 - r^2)y[i]^n - y[i]^(n-1) + r^2(y[i+1]^n + y[i-1]^n)

分别设定 r = 0.5、1.0、1.5，运行模拟，观察波传播和反射过程，比较数值准确性和稳定性。

这部分内容完全来自教材关于稳定性与 r 的总结。

## 与习题 6.3 有关的内容

习题 6.3 要求你构造一个不会分裂、只向一个方向传播的波包。教材中相关内容主要在以下几个地方出现。

教材指出波动方程的解一般由 f(x - c t) 和 g(x + c t) 两部分组成。如果一开始只指定位形，而把初速度设为零，那么通常会让 f 和 g 都不为零，导致波立即分裂成左右两部分。教材直接给出了关键提示：为了构造单向传播的波，必须同时指定初始位移和初始速度。

对于只向右传播的波，理论上需要：

y(x,0) = f(x)

(∂y/∂t)(x,0) = - c * f'(x)

在离散模型中，这意味着：

第一层数据 y[i]^0 = f(x_i)

第二层数据必须按差分近似给出：

y[i]^1 = f(x_i) - (r/2)*( f(x_i + Δx) - f(x_i - Δx) )

这样设置初速度后，g(x + c t) 被消去，只剩下向右传播的波。

因此，习题 6.3 的目标是：通过正确设置第一层和第二层初始条件，使波包只向一个方向移动。这部分内容完全对应教材给学生的"必须指定初速度"的提示。

### 技术细节

#### 初速度设置（习题 6.3）

对于向右传播（direction = +1）：
```
y[i]^1 = f(x_i) - r * dx * df/dx
```

对于向左传播（direction = -1）：
```
y[i]^1 = f(x_i) + r * dx * df/dx
```

其中 df/dx 使用中心差分近似：
```
df/dx ≈ (f(x_i + dx) - f(x_i - dx)) / (2*dx)
```

## 关键结论

1. **CFL 条件的重要性**：r=1 时算法最准确，r>1 时会发散，这验证了 Courant-Friedrichs-Lewy (CFL) 稳定性条件

2. **单向波的构造**：必须同时指定初始位移和初速度才能实现单向传播，仅指定位移会导致波包分裂

3. **数值发散的可视化**：r=1.5 的 GIF 动画清晰展示了数值不稳定性如何在几十步内将微小误差放大到天文数字

4. **边界反射**：固定端边界条件会导致波翻转反射，这是波动方程的经典性质
