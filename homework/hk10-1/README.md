# hk10-1 - 波动方程数值解

使用有限差分法求解一维波动方程。

## 物理模型

一维波动方程：
```
∂²y/∂t² = c² ∂²y/∂x²
```

差分格式：
```
y[i]^(n+1) = 2(1-r²)y[i]^n - y[i]^(n-1) + r²(y[i+1]^n + y[i-1]^n)
```

其中 r = c·dt/dx 是 Courant 数。

## 功能特性

### 问题 6.2: 稳定性分析

比较不同 r 值的数值稳定性：
- r = 0.5: 稳定，但反射处有小波纹
- r = 1.0: 最精确，误差完美抵消
- r > 1.0: 不稳定，数值发散

### 问题 6.3: 单向传播波包

构造仅向一个方向传播的高斯波包，无分裂现象。
