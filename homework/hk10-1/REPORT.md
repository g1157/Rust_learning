## 引言

波动方程是描述波在介质中传播的基本偏微分方程，在物理学、工程学等领域有广泛应用。对于一维弦的横向振动，波动方程可以写为：

```
∂²y/∂t² = c² ∂²y/∂x²
```

其中：
- `y(x,t)` 是弦在位置 x、时刻 t 的位移
- `c = √(T/μ)` 是波速
- `T` 是张力
- `μ` 是线密度

### 实验目标

1. 使用有限差分法数值求解波动方程
2. 研究 Courant 数 `r = cΔt/Δx` 对算法稳定性的影响
3. 通过设置初速度构造单向传播的波包

## 理论背景

### 波动方程的差分格式

将空间和时间都离散化，令：
- `xᵢ = iΔx`
- `tₙ = nΔt`
- `yᵢⁿ = y(xᵢ, tₙ)`

使用中心差分近似二阶导数：

**空间二阶导数：**
```
∂²y/∂x² ≈ (yᵢ₊₁ⁿ - 2yᵢⁿ + yᵢ₋₁ⁿ) / (Δx)²
```

**时间二阶导数：**
```
∂²y/∂t² ≈ (yᵢⁿ⁺¹ - 2yᵢⁿ + yᵢⁿ⁻¹) / (Δt)²
```

代入波动方程，得到**差分格式**：

```
yᵢⁿ⁺¹ = 2(1-r²)yᵢⁿ - yᵢⁿ⁻¹ + r²(yᵢ₊₁ⁿ + yᵢ₋₁ⁿ)
```

其中 **Courant 数**定义为：
```
r = cΔt/Δx
```

### CFL 稳定性条件

**Courant-Friedrichs-Lewy (CFL) 条件**指出，要保证数值格式稳定，必须满足：

```
r ≤ 1
```

**物理意义：** 数值格式中信息传播的速度（Δx/Δt）必须大于等于物理波速 c，否则网格无法捕捉波的传播，导致数值发散。

**特别地**，当 `r = 1` 时，算法达到最优精度，因为此时离散格式的色散关系与连续方程完全一致。

### 波的一般解

一维波动方程的通解可以写为 **d'Alembert 解**：

```
y(x,t) = f(x - ct) + g(x + ct)
```

其中：
- `f` 表示向右传播的波
- `g` 表示向左传播的波

如果初始条件为：
```
y(x,0) = φ(x)
∂y/∂t(x,0) = ψ(x)
```

则可以确定：
```
f(x) + g(x) = φ(x)
-cf'(x) + cg'(x) = ψ(x)
```

**特别地**，若要构造只向右传播的波（`g=0`），需要设置：
```
ψ(x) = -c·φ'(x)
```

若要构造只向左传播的波（`f=0`），需要设置：
```
ψ(x) = +c·φ'(x)
```

### 离散初速度条件

在差分格式中，初速度通过前两个时间层的关系来设定。使用中心差分近似初速度：

```
∂y/∂t(xᵢ, 0) ≈ (yᵢ¹ - yᵢ⁻¹) / (2Δt)
```

结合对称性和差分格式，可得：

```
yᵢ¹ = yᵢ⁰ + Δt·ψ(xᵢ) + (r²/2)(yᵢ₊₁⁰ - 2yᵢ⁰ + yᵢ₋₁⁰)
```

对于**向右传播的波**，`ψ(x) = -c·φ'(x)`，使用中心差分近似导数：

```
yᵢ¹ = φ(xᵢ) - (r/2)[φ(xᵢ₊₁) - φ(xᵢ₋₁)]
```

对于**向左传播的波**，符号相反：

```
yᵢ¹ = φ(xᵢ) + (r/2)[φ(xᵢ₊₁) - φ(xᵢ₋₁)]
```

### 初始条件

#### 习题 6.2（双向传播）

```
y(x, 0) = exp[-(x-5)²/0.5]
∂y/∂t(x, 0) = 0
```

波包位于中心位置，初速度为零，导致波包分裂成左右两波。

#### 习题 6.3（单向传播）

**向右传播：**
```
y(x, 0) = exp[-(x-3)²/0.5]
∂y/∂t(x, 0) = -c·dφ/dx
```

**向左传播：**
```
y(x, 0) = exp[-(x-7)²/0.5]
∂y/∂t(x, 0) = +c·dφ/dx
```

## 实现方法

### 算法流程

1. **初始化**：设置 y⁰ 和 y¹（根据初速度条件）

2. **时间演化循环**（n = 1, 2, ..., Nₜ-1）：
   - 对每个内部网格点 i = 1, 2, ..., Nₓ-2，计算：
     ```
     yᵢⁿ⁺¹ = 2(1-r²)yᵢⁿ - yᵢⁿ⁻¹ + r²(yᵢ₊₁ⁿ + yᵢ₋₁ⁿ)
     ```
   - 应用边界条件：`y₀ⁿ⁺¹ = yₙₓ₋₁ⁿ⁺¹ = 0`
   - 更新时间层：`yⁿ⁻¹ ← yⁿ`，`yⁿ ← yⁿ⁺¹`

3. **记录快照**用于可视化

### 技术实现

本实验使用 **Rust 语言**实现，具有以下优势：
- **性能**：编译后的代码接近 C/C++ 性能
- **安全**：编译期内存安全检查，避免运行时错误
- **并发**：内置并发支持，便于扩展到并行计算

主要使用的库：
- `plotters`：生成 GIF 动画
- `plotly`：生成交互式 HTML 图表

核心数据结构：

```rust
struct WaveSolver {
    nx: usize,           // 空间网格点数
    dx: f64,             // 空间步长
    r: f64,              // Courant 数
    y_prev: Vec<f64>,    // y^(n-1)
    y_curr: Vec<f64>,    // y^n
    y_next: Vec<f64>,    // y^(n+1)
}
```

## 结果与分析

### 习题 6.2：不同 r 值的稳定性比较

#### r = 0.5 的情况

当 `r < 1` 时，算法满足 CFL 条件，数值稳定。从动画中观察到：

- ✅ 初始高斯波包立即分裂成左右两个波包
- ✅ 两波包以恒定速度向边界传播
- ✅ 到达边界后发生反射并翻转（符合固定端边界条件）
- ✅ 波形在传播和反射过程中基本保持形状
- ⚠️ 可能在反射处产生微小的数值波纹（教材所述的 "extra bumps"）

**数值稳定性**：`max|y| ≈ 1.0`，与初始振幅一致，无发散迹象。

**文件**：`problem_6_2_r_0_5.gif`, `problem_6_2_r_0_5.html`

---

#### r = 1.0 的情况

当 `r = 1` 时，达到 CFL 条件的临界值，这是理论上的**最优选择**。观察到：

- ✅ 波的传播行为与 r=0.5 相似
- ✅ 反射时波形保持得更好，数值耗散最小
- ✅ 几乎看不到数值波纹
- ✅ 能量守恒最好

**理论分析**：当 r=1 时，差分格式变为：
```
yᵢⁿ⁺¹ = yᵢ₊₁ⁿ + yᵢ₋₁ⁿ - yᵢⁿ⁻¹
```
此时格式的色散关系与连续方程完全匹配，因此精度最高。

**文件**：`problem_6_2_r_1.gif`, `problem_6_2_r_1.html`

---

#### r = 1.5 的情况

当 `r > 1` 时，**违反 CFL 条件**，算法不稳定。观察到明显的三个阶段：

**第一阶段（步数 0-20）：**
- 波包表面上正常分裂和传播
- 但已经开始积累数值误差

**第二阶段（步数 20-50）：**
- ⚠️ 出现明显的数值振荡
- ⚠️ 波形开始扭曲，产生高频噪声
- ⚠️ 振幅开始指数增长

**第三阶段（步数 50-300）：**
- ❌ 数值完全失控，发散到 **10²³³**
- ❌ 在 GIF 动画中看到波形"飞出"画面边界
- ❌ 物理意义完全丧失

**发散机制**：当 r > 1 时，物理波速 c 大于数值波速 Δx/Δt，导致网格无法正确捕捉波的传播，微小误差被指数放大。

**文件**：`problem_6_2_r_1_5.gif`, `problem_6_2_r_1_5.html`

---

#### 结果对比

| 特性 | r=0.5 | r=1.0 | r=1.5 |
|------|-------|-------|-------|
| 数值稳定性 | 稳定 | 稳定 | **不稳定** |
| 最大振幅 | ~1.0 | ~1.0 | ~10²³³ |
| 反射处波形 | 良好，有小波纹 | **最佳** | 发散 |
| 能量守恒 | 良好 | **最佳** | 不守恒 |
| 计算效率 | 低（需小时间步） | **最优** | - |

### 习题 6.3：单向传播波包

#### 向右传播波包

初始位置 `x₀ = 3.0 m`，设置初速度 `v = -c·φ'(x)`。观察结果：

- ✅ **无分裂**：波包保持完整，不分裂成左右两波
- ✅ **向右传播**：波包以速度 c = 1.0 m/s 向右移动
- ✅ **到达右边界**（x = 10 m，约 t = 7 s）：发生反射并翻转
- ✅ **反射后**：变成向左传播的波，但这是物理反射，不是初始分裂

**理论验证**：通过设置 `ψ(x) = -c·φ'(x)`，确保 d'Alembert 解中 `g(x+ct) = 0`，只保留 `f(x-ct)` 项。

**文件**：`problem_6_3_rightward.gif`, `problem_6_3_rightward.html`

---

#### 向左传播波包

初始位置 `x₀ = 7.0 m`，设置初速度 `v = +c·φ'(x)`。观察结果：

- ✅ **无分裂**：波包保持完整
- ✅ **向左传播**：波包向左移动
- ✅ **到达左边界**（x = 0 m，约 t = 7 s）：反射并翻转
- ✅ **反射后**：变成向右传播的波

**文件**：`problem_6_3_leftward.gif`, `problem_6_3_leftward.html`

---

#### 与双向传播的对比

| 特性 | 双向传播 | 单向传播 |
|------|----------|----------|
| 初速度 | v = 0 | v = ∓c·φ'(x) |
| 初始分裂 | **是** | **否** |
| 传播方向 | 左右同时 | 单一方向 |
| 能量分布 | 分散到两个波包 | 集中在一个波包 |
| 应用场景 | 驻波、共振 | 信号传输、脉冲 |

**关键结论**：初速度条件对波的传播方向起决定性作用，这在信号处理和波导设计中有重要应用。

## 结论

通过本次实验，我们得到以下重要结论：

### 关于数值稳定性

1. **CFL 条件的必要性**：当 r > 1 时，算法必然发散，这验证了 Courant-Friedrichs-Lewy 稳定性条件的重要性。

2. **最优 Courant 数**：r = 1 时算法达到最优精度，这是理论和实践的完美结合。

3. **稳定性裕度**：即使 r < 1，也不是越小越好，因为会降低计算效率且可能增加数值耗散。

4. **发散速度**：r = 1.5 的情况下，仅 30-50 步就出现明显发散，说明不稳定性的增长非常快。

### 关于单向传播

1. **初速度的关键作用**：只有同时指定初始位移和初速度，才能控制波的传播方向。

2. **理论与数值的一致性**：离散格式正确实现了 d'Alembert 解的单向波条件。

3. **能量局域化**：单向波将能量集中在一个方向，这在实际应用中很重要。

### 方法论启示

1. **可视化的重要性**：GIF 动画直观展示了数值不稳定性的发展过程，比单纯的数值更有说服力。

2. **多参数对比**：通过系统地改变 r 值，清晰地看到了 CFL 条件的作用边界。

3. **实现的可靠性**：Rust 语言的类型安全和性能优势使得实现既高效又可靠。
