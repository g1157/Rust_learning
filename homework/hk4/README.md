# hk4 - 放射性衰变模拟

模拟双衰变过程 A→B 的数值计算项目。

## 功能特性

- 使用欧拉方法进行数值积分
- 支持多个衰变时间常数比例 (τ_b/τ_a) 的对比
- 交互式绘图输出 (HTML)

## 物理模型

模拟放射性衰变链 A→B：
- A 衰变为 B，衰变常数 τ_a
- B 继续衰变，衰变常数 τ_b
- 研究不同 τ_b/τ_a 比例下的衰变曲线

## 项目结构

```
hk4/
├── src/
│   ├── main.rs           # 主程序
│   ├── decay_data.rs     # 衰变数据结构
│   └── draw_decay_data.rs # 绘图模块
└── Cargo.toml
```

## 运行

```bash
cargo run
# 输入多个 τ_b/τ_a 比例值，空格分隔
```

## 输出

生成 HTML 格式的交互式图表，展示不同参数下的衰变曲线。
