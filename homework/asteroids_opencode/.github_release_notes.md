## 🎮 Asteroids 小行星游戏 v1.0.0

一个用 Rust 和 Macroquad 开发的现代化小行星街机游戏，具有完善的音频系统和性能优化。

### ✨ 主要特性

#### 🎯 游戏模式
- **生存模式**: 双人合作清除逐渐增强的小行星波次
- **对战模式**: 竞技夺旗战，支持 Best of 3/5 多回合系统

#### 🔊 音频系统
- **专业音频处理**: 250ms 超长淡出，完全消除音频杂音
- **可调音量**: 默认 1%，可在设置中调节 0-100%
- **音频淡出配置**:
  - 射击音效: 250ms (66% 占比)
  - 道具音效: 150ms (7.5% 占比)
  - 末尾振幅归零，无任何爆音

#### ⚡ 性能优化
- **QuadTree 空间分区**: 碰撞检测从 O(n²) 优化到 O(n log n)
- **高效粒子系统**: 支持 1000+ 并发粒子不卡顿
- **实时性能监控**: 按 F3 查看 FPS、实体数、QuadTree 深度

#### 💫 游戏体验
- **粒子效果**: 爆炸、推进器、子弹尾迹
- **击杀连击系统**: 连续击杀获得射速和速度加成
- **慢动作效果**: 高连击时触发慢动作（0.4x-0.6x 速度）
- **屏幕震动**: 基于事件强度的动态震动
- **多种武器**: 普通弹、散射弹、穿透弹

#### 🎨 可定制设置
- 生命值 (1-9)
- 飞船速度 (0.5x-2.0x)
- 小行星速度 (0.5x-2.0x)
- 音量 (0%-100%, 1% 步长)
- 字体选择 (4种)
- 武器切换、屏幕震动、慢动作开关

### 📦 快速开始

#### 前置要求
- Rust 1.70+ (2024 edition)
- Cargo

#### 安装运行
```bash
# 克隆仓库
git clone https://github.com/g1157/Rust.git
cd Rust/homework/asteroids_opencode

# 运行游戏
cargo run --release
```

#### 首次运行设置
1. **音频文件准备** (必需)
   - 将音频文件放入 `assets/sounds/` 目录
   - 运行淡出处理: `python3 fix_shoot_fadeout.py`
   - 详见 [SETUP_ASSETS.md](homework/asteroids_opencode/SETUP_ASSETS.md)

2. **字体设置** (可选)
   - Linux/macOS: `./setup_fonts.sh`
   - 或在游戏中选择 "Default" 字体

3. **调整音量**
   - 默认 1% 较小，建议在设置中调到 5-10%

### 🎮 游戏操作

#### 玩家 1
- W/A/D: 推进/左转/右转
- J 或 F: 射击
- Q: 切换武器（如果启用）

#### 玩家 2
- ↑/←/→: 推进/左转/右转
- 1 或 Numpad 1: 射击

#### 通用
- Enter: 开始游戏/确认
- Esc/P: 暂停
- M: 返回主菜单
- F3: 性能面板
