## 🧪 测试步骤

### 方法 1: 完整游戏测试
1. 打开浏览器访问: http://localhost:8000
2. 选择 "Online" 模式
3. 输入昵称（例如: Player1）
4. 按 Enter 连接服务器
5. 选择游戏模式:
   - 按 1 = Survival
   - 按 2 = Duel
6. 等待匹配结果

### 方法 2: WebSocket 单独测试
1. 打开: http://localhost:8000/test_websocket.html
2. 点击 "连接服务器"
3. 观察连接日志
4. 点击 "加入队列" 测试消息发送
5. 点击 "发送 Ping" 测试心跳

## 📊 预期行为

### 连接流程
```
客户端启动
  ↓
输入昵称
  ↓
连接 ws://localhost:9001
  ↓ (应该收到 Connected 消息)
选择模式并加入队列
  ↓ (发送 JoinQueue)
等待匹配
  ↓ (应该收到 MatchFound 或等待)
进入游戏
```

### 服务器响应
- **连接成功**: `{"type":"Connected","player_id":"uuid"}`
- **匹配成功**: `{"type":"MatchFound","room_id":"...","players":[...],"mode":"Survival"}`
- **心跳响应**: `{"type":"Pong"}`

## 🐛 已知问题

### 1. 单人匹配问题
- **问题**: 单个玩家加入队列后会一直等待
- **原因**: 服务器需要 2 个玩家才能开始匹配
- **解决**: 需要两个浏览器标签页同时测试

### 2. 游戏状态同步未实现
- **状态**: ⏸️ 待开发
- **影响**: 匹配成功后无法进入实际游戏
- **需要**: 实现 Playing 状态的网络同步

## 🔧 调试命令

### 查看服务器日志
```bash
# 如果服务器输出到文件
tail -f server/server.log

# 如果服务器在前台运行
cd server && cargo run
```

### 检查端口占用
```bash
# WebSocket 服务器
lsof -i :9001

# Web 服务器
lsof -i :8000
```

### 停止服务
```bash
# 停止 WebSocket 服务器
pkill -f 'cargo run.*server'

# 停止 Web 服务器
pkill -f 'python3.*http.server'
```
