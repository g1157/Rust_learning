# 音效文件

将以下音效文件放在此目录以启用游戏音效：

## 所需文件

- `shoot.wav` - 射击音效
- `explosion.wav` - 小行星爆炸音效
- `thrust.wav` - 推进器音效（可选）
- `powerup.wav` - 拾取道具音效
- `hit.wav` - 飞船碰撞音效

## 音频格式

支持的格式：
- WAV (.wav)
- OGG Vorbis (.ogg)

## 获取免费音效

推荐资源：
- https://freesound.org/
- https://opengameart.org/
- https://kenney.nl/assets (特别推荐 Kenney 的免费游戏音效包)

## 注意

如果没有音频文件，游戏将在静默模式下运行（不播放声音），但所有功能仍正常工作。
