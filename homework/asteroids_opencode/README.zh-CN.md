# Asteroids 小行星游戏 🚀

现代化的经典小行星街机游戏重制版，使用 Rust 和 Macroquad 构建。提供合作生存模式和竞技对战模式，具有流畅的游戏体验、粒子效果和音效系统。

## 功能特性

- **生存模式**：与朋友组队清除一波又一波的小行星，竞争最高分数
  - 逐波推进系统，带胜利暂停画面
  - 渐进式难度（每波增加更多小行星）
- **对战模式**：在竞技夺旗战中与对手一决高下
  - **多回合系统**：Best of 3（先赢 2 局），支持 Best of 5
  - **击杀连击**：连续击杀获得射速和速度加成
  - 回合结束画面显示当前战况
- **本地双人**：两名玩家共用一个键盘
- **能量道具**：护盾拾取物提供临时无敌
- **流畅物理**：基于动量的真实飞船控制
- **粒子效果**： 
  - 小行星爆炸时的彩色粒子效果
  - 加速时的推进器火焰
  - 碰撞冲击效果
- **音效系统**：
  - 音量可调（默认 1%）
  - 专业音频淡出处理（250ms/150ms）
  - 无音频杂音或爆音
  - 详见 `AUDIO_FADEOUT.md` 技术文档
- **精致 UI**：清爽的渐变、阴影和视觉反馈
- **性能优化**：QuadTree 空间分区优化碰撞检测（O(n²) → O(n log n)）

## 操作控制

### 玩家 1
- **W/A/D**：推进 / 左转 / 右转
- **J 或 F**：射击

### 玩家 2
- **↑/←/→**：推进 / 左转 / 右转
- **1 或 小键盘 1**：射击

### 通用控制
- **Enter**：开始游戏 / 确认选择
- **Esc 或 P**：暂停游戏
- **M**：返回模式选择
- **F3**：切换调试面板（FPS、实体数、四叉树深度）
- **←/→ 或 A/D**（在设置中）：调整音量和其他设置

## 游戏设置

从主菜单访问设置来自定义游戏体验：

- **初始生命值**：1-9 条生命（默认：3）
- **飞船速度**：0.5x - 2.0x 推进和旋转速度倍数（默认：1.0x）
- **飞船大小**：0.5x - 2.0x 渲染和碰撞大小倍数（默认：1.0x）
  - 调整视觉大小、碰撞检测、护盾半径、子弹发射位置
  - 适用于辅助功能和个人喜好
- **小行星速度**：0.5x - 2.0x 倍数（默认：1.0x）
- **音量**：0% - 100%（默认：1%）
  - 在设置中使用 ←/→ 或 A/D 键调节，步长 1%
  - 音量使用相对倍数（0.0 - 1.0）
- **字体选择**：默认 / DejaVu Sans / Ubuntu / 自定义
- **武器切换**：启用/禁用 Q 键武器切换
- **屏幕震动**：开关屏幕震动效果
- **慢动作**：开关高连击时的慢动作
- **调试面板**：默认是否显示 F3 调试信息

## 音频系统

### 音效
- **shoot.wav**：射击音效（250ms 淡出，66% 占比）
- **powerup.wav**：道具拾取音效（150ms 淡出，7.5% 占比）
- 所有音效均经过专业淡出处理，消除音频杂音

### 音量控制
- 默认音量：**1%**（0.01 相对倍数）
- 在设置菜单中使用 ←/→ 或 A/D 键调节
- 范围：0% - 100%，步长 1%

### 音频处理
所有音效文件使用线性淡出防止"爆音"或"咔嗒"声：
- 短音效（如射击）使用更长的淡出比例
- 技术细节见 `AUDIO_FADEOUT.md` 和 `SHOOT_FADEOUT_FIX.md`
- 原始音频备份在 `assets/sounds/original_backup/`

## 游戏模式

### 生存模式
与队友合作消灭逐渐增强的小行星波次。每个被摧毁的小行星会分裂成更小的碎片。收集护盾道具来抵御碰撞。

**波次系统：**
- 清除所有小行星触发 2 秒胜利暂停
- 下一波生成额外 2 个小行星
- 所有玩家阵亡时游戏结束

**计分规则：**
- 大型小行星：20 分
- 中型小行星：50 分  
- 小型小行星：100 分

**视觉效果：**
- 粒子爆炸使用摧毁者的颜色
- 推进器粒子尾迹
- 护盾道具发光效果

### 对战模式
在对手之前夺取旗帜。首个达到目标分数的玩家赢得当前回合。

**回合系统：**
- Best of 3：先赢 2 局获得比赛胜利
- 支持 Best of 5 模式（先赢 3 局）
- 回合结束画面显示当前局数和比分

**击杀连击系统：**
- **连击加成**：连续击杀小行星获得临时增强
  - 每次连击降低 15% 射击冷却时间（最多 3 次）
  - 每次连击增加 30 像素/秒 移动速度（最多 3 次）
- **连击等级**：
  - 2-3 连击：Double Kill!
  - 4-5 连击：Triple Kill!
  - 6-9 连击：Mega Kill!
  - 10+ 连击：UNSTOPPABLE!
- 5 秒内无击杀自动重置连击

**游戏机制：**
- 旗帜重生延迟 1.5 秒
- 支持弹幕对战（击中对手飞船）
- 战略性的旗帜争夺战

## 技术细节

- **引擎**：[Macroquad](https://github.com/not-fl3/macroquad) 0.4
- **语言**：Rust (2024 edition)
- **架构**：Entity-component 模式，模块化分离
- **物理**：基于时间增量的更新，约 60 FPS
- **碰撞检测**：QuadTree 空间分区优化，O(log n) 性能
- **粒子系统**：自定义实现，支持最多 1000 个并发粒子
- **音频**：Macroquad 音频 + 自定义淡出处理（250ms/150ms）
- **音量系统**：可调音量，默认 1%，步长 1%
- **慢动作**：基于时间缩放的慢动作（0.4x-0.6x）
- **屏幕震动**：基于事件强度的动态震动

## 性能优化

### QuadTree 空间分区
- **算法复杂度**：从 O(n²) 降低到 O(n log n)
- **实现细节**：
  - 递归四叉树分割（最大深度 5 层）
  - 每节点最多存储 4 个对象
  - 智能查询范围减少不必要的检测
- **应用场景**：
  - 玩家飞船与小行星碰撞
  - 子弹与小行星碰撞
- **性能提升**：在大量小行星场景下显著减少 CPU 开销
