# Guessing Game - 猜数字游戏

一个经典的猜数字游戏，用于学习 Rust 基础语法。

## 功能特性

- 多轮游戏模式（默认 2 轮）
- 随机生成 1-100 之间的秘密数字
- 智能输入验证，过滤无效输入
- 记录并显示最佳成绩（最少猜测次数）

## 技术要点

- **随机数生成**: 使用 `rand` crate 生成随机数
- **错误处理**: 使用 `match` 表达式处理用户输入
- **循环控制**: `loop` 和 `break` 的使用
- **比较运算**: `std::cmp::Ordering` 枚举类型

## 运行

```bash
cargo run
```

## 游戏流程

1. 程序生成一个 1-100 之间的随机数
2. 用户输入猜测的数字
3. 程序提示"太大了"或"太小了"
4. 猜对后显示本轮猜测次数
5. 完成所有轮次后显示最佳成绩
