# hk5 - 炮弹轨迹模拟

考虑空气阻力的炮弹弹道模拟项目。

## 功能特性

- 支持等温大气和绝热大气两种空气模型
- JSON 配置文件定义多个炮弹参数
- 使用 Plotly 生成交互式轨迹图

## 物理模型

### 空气阻力

运动方程包含空气阻力项：
- 等温模型：密度随高度指数衰减
- 绝热模型：密度随高度幂律衰减

### 参数

- 初始位置 (x0, y0)
- 发射角度 (theta)
- 初始速度 (v0)
- 空气阻力系数

## 配置文件

`cannon_config.json` 定义炮弹参数：

```json
{
  "cannon1": {
    "x0": 0.0,
    "y0": 0.0,
    "theta": 45.0,
    "v0": 700.0,
    "resistance_type": "Isothermal"
  }
}
```

## 运行

```bash
cargo run
```

## 输出

- `cannon_traces.html` - 交互式轨迹图
